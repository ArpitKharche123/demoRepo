Service Access Guide

1. Service Registry (Eureka)
URL: http://localhost:8761
Purpose: View all registered microservices
Dashboard: Shows running services and their health status

2. API Gateway
URL: http://localhost:8083
Port: 8083
Routes:
Products: http://localhost:8083/products/** → Product Service (8081)
Orders: http://localhost:8083/orders/** → Order Service (8082)
Health: http://localhost:8083/actuator/health
Metrics: http://localhost:8083/actuator/prometheus

3. Product Service
URL: http://localhost:8081
Port: 8081
Direct Access: http://localhost:8081/products
Health: http://localhost:8081/actuator/health
Metrics: http://localhost:8081/actuator/prometheus
Database: PostgreSQL (product_db)

4. Order Service
URL: http://localhost:8082
Port: 8082
Direct Access: http://localhost:8082/orders
Health: http://localhost:8082/actuator/health
Metrics: http://localhost:8082/actuator/prometheus
Database: PostgreSQL (order_db)

5. Prometheus (Monitoring)
URL: http://localhost:9090
Port: 9090 (localhost only)
Purpose: Collects metrics from all services
Query Interface: Built-in UI for querying metrics

6. PostgreSQL Database
Host: localhost
Port: 5432
Username: postgres
Password: root1234
Databases: product_db, order_db
Connection String: jdbc:postgresql://localhost:5432/product_db

7. Redis Cluster
Ports: 7000-7005 (6 nodes)
Connection: localhost:7000,localhost:7001,localhost:7002,localhost:7003,localhost:7004,localhost:7005
Purpose: Caching for Product & Order services

Common Queries in Prometheus

Visit http://localhost:9090 and try these queries:

Query	                                          Purpose
http_server_requests_seconds_count          	HTTP request count
jvm_memory_used_bytes	                        JVM memory usage
process_uptime_seconds	                        Application uptime
jvm_threads_live	                            Active threads
jvm_gc_collections_count	                    Garbage collection count

All services are discoverable via Eureka and communicate through the microservices Docker network!
